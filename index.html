elasticElasticsearch is a vector database

Space: three times, one card each.

Lexical and vector search share one index and one request. The embedding, reranking and OCR models run inside the platform through EIS, and the same roles run on ML nodes when there is no internet. Vectors are quantized to one bit with DiskBBQ so the index scales past memory. No second system, no glue.

How it works · semantic_text

semantic_text: the mapping is the pipeline.

What happens to a document
bodychunkEIS · jina-v5-textvectorsbbq_disk
1One field type. Chunking, embedding and quantization happen inside the index, at write time and at query time.
2DiskBBQ. One bit per dimension on disk, rescored against the originals. The same index that holds 80 articles holds 100 million.
3Swap the endpoint, keep the mapping. ELSER, E5 or any Hugging Face model imported with Eland runs this field offline.

elasticsemantic_text and EIS

Space: three times.

This is the whole vector pipeline: one field in the mapping that names an inference endpoint. Chunking, embedding and quantization happen in the index. DiskBBQ stores one bit per dimension on disk and rescores. And because the endpoint is an abstraction, the same mapping runs with ELSER or an Eland-imported model when there is no internet. elasticHybrid: fuse by rank

Space: vector column, then the fused column.

Identifiers are where vectors are fuzzy: the ticket id looks like eleven other ids, so the vector column has the look-alikes on top. BM25 pins the exact id. Reciprocal rank fusion merges the two lists by rank, so the exact ticket stays first and the look-alikes follow. No score normalization, no tuning. In the demo: CRM cube, pill TKT-20481, three modes.

Space: four times, one slab drops each time, then the agent line.

Bottom slab: retrieval over billions, BM25 and vectors fused, cheap per document. Middle: tuning, query rules and weights, no model changes. Top: a reranker that reads the top fifty against the question. Each layer sees fewer documents and spends more on each. Everything above feeds the agent.
